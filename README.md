# Ashton Caspe Portfolio

Astro rebuild of Ashton James D. Caspe's portfolio. The previous static site is preserved in `legacy/` while the revamp is developed on the `revamp` branch.

## Local development

```sh
npm install
npm run dev
```

Open `http://localhost:4321/portfolio/`. The `/portfolio` base path matches the `Kscopee/portfolio` GitHub Pages repository.

## Production check

```sh
npm run build
npm run preview
```

The static production output is written to `dist/`.
